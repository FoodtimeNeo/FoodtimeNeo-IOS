# iOS 架构边界

本次只建立职责边界。后续可用 SwiftUI、UIKit 或经用户确认的其它技术实现，目录不强制选定 UI、数据库或依赖管理方案。

```text
Features / SharedUI
        ↓
App 中的导航与依赖组装 → Domain 用例与接口
                              ↑
                  Data 与 Platform 的可替换适配
```

| 目录 | 责任 | 禁止耦合 |
|---|---|---|
| App | 依赖组装、会话启动/失效、导航和深链上下文 | 不集中实现全部业务或保存明文密码 |
| Domain | 领域模型、用例、权限投影、业务端口和幂等规则 | 不依赖 SwiftUI/UIKit、HTTP DTO 或存储 SDK |
| Data | 既有 API 的 DTO 映射、错误/分页/时间/金额解析、缓存和持久化 | 不绕过后端，不向页面泄露数据库实体 |
| Platform | Keychain、相册/文件、系统分享、剪贴板、通知及生命周期 | 不决定审核、处罚、账号资格等业务结论 |
| Features | 按功能组合用例和界面状态，处理输入与重试 | 不拼通用万能 action，不把所有页面塞进一个大对象 |
| SharedUI | 手账色彩/字体/图标、空错状态、图片与可访问控件 | 不直接执行领域写操作或隐藏服务端错误 |

## 共用后端的契约

复用 `/api/v1`、当前 ApiResponse、Cookie 会话、CSRF、能力、revision、错误码和幂等标识。接口以最新 Backend Controller/DTO 与 Android RemoteRepository/Json adapters 交叉核对，不照抄历史草案。普通分页与 cursor 分页分别建模；金额用十进制且 null 不当0，时间携带时区并遵守已约定 UTC+8 日界。

数据传输对象、领域对象和界面状态分开。服务地址、系统能力和存储实现通过注入替换；本机测试不能默认写入生产服务。共享文件和图片关联失败时复用合法上传引用，避免重复提交；先验证上传所属账号。

## 会话与并发

会话凭据安全保存且按来源隔离，不缓存角色绕过验证。验证码、受限申诉会话和注销/解绑规则沿用服务器。账号切换、注销、权限撤回或页面切换后，旧网络响应、图片、上传结果和后台任务不能继续写入新账号/新页面。

浏览历史与帖子浏览量分别处理；一次打开的浏览量请求重试复用编号，评论/点赞/刷新不额外增加。通知消息与系统投递分开，投递失败不撤销业务结果。后台任务不能阻塞评论或普通读取。

## 资源与配置

字体、平面 Emoji、插画、地图和区域数据优先核对现有 Android 资源及来源声明后复用，保留许可说明。地图轮廓、目录关联、真实入口和未来道路网络分离；当前复刻目标没有 GPS 或自动导航。不要为了抄目录结构恢复已移除字段。

构建环境、接口地址、签名和版本阶段分别配置。实际框架、最低版本和包标识确认后，再建立可运行工程、模拟器 scheme、测试 target 和构建门禁。
